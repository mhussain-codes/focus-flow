# Focus Flow ⏱️

A calm, browser-based Pomodoro timer for study and focused work. No install, account, or distraction required.

## Features

- 25-minute focus and 5-minute break sessions
- Start, pause, reset, and switch modes
- Add a task for the current session
- Focus session count saved in your browser
- Responsive layout with keyboard-friendly controls

## Run it

Open `index.html` in any modern browser. Everything runs locally in the page.

## Built with

HTML, CSS, and vanilla JavaScript.
